Note on determinism
-------------------
`main.py` substitutes `to_time = datetime.now()` when the prompt is
left blank. To get a stable reproducible baseline, supply explicit
`from-time` / `to-time` strings (yyyy-mm-dd) instead of pressing
Enter — that pins the replay window so identical params produce
identical output.

Wave / Tide re-baseline commands
--------------------------------
The wave and tide engines do NOT go through `strategies.orderflow.backtest()`,
so their reports were not affected by Phase 13X. They can still be
re-baselined for completeness:

    # Wave (1h, single-timeframe backtest)
    python -m wave backtest \
      --exchange binance --symbol BTCUSDT --timeframe 1h \
      --from-time 2024-01-01 --to-time 2024-12-31 \
      --max-position-base 1.0 --sizing-mode base \
      --name BTCUSDT_post13Y_baseline

    # Wave optimisation (population=20, 12 generations)
    python -m wave optimise \
      --exchange binance --symbol BTCUSDT --timeframe 1h \
      --from-time 2024-01-01 --to-time 2024-12-31 \
      --pop-size 20 --generations 12 --top-n 5 \
      --max-position-base 1.0 --sizing-mode base

    # Tide (single backtest)
    python -m tide backtest \
      --exchange binance --symbol BTCUSDT --timeframe 1h \
      --from-time 2024-01-01 --to-time 2024-12-31 \
      --name BTCUSDT_post13Y_baseline

    # Tide optimisation
    python -m tide optimise \
      --exchange binance --symbol BTCUSDT --timeframe 1h \
      --from-time 2024-01-01 --to-time 2024-12-31 \
      --population 20 --generations 12 --top-k 5
